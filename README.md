# Garden Shop · Dashboard de Estoque e Reposição

Projeto da Lista 02 de **Lucas Girardi**: dashboard funcional de estoque e reposição da Garden Shop, construído com apoio de IA generativa.

| Documento | Conteúdo |
|---|---|
| [PRD.md](PRD.md) | Problema, usuários, escopo, indicadores, regras de negócio e critérios de aceitação |
| [SPEC.md](SPEC.md) | Especificação técnica: dados, fórmulas, filtros, erros, módulos e exemplos esperados |
| [AGENTS.md](AGENTS.md) | Instruções para agentes de IA, com ambiente, comandos de execução e testes e cuidados com os dados |

Execução rápida:

```bash
pip install -r requirements.txt
streamlit run app.py
```
